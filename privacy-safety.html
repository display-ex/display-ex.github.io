Security, Code Signing, and Privacy — Is Display EX Safe?

Yes — Display EX ships as a code‑signed Windows installer from a single canonical URL. This page explains how to verify integrity and how we handle privacy and analytics.

Is Display EX safe to install?

  • Official, code‑signed installer for Windows 11/10 (64‑bit).
  • Distributed only via the canonical link below to prevent spoofing.
  • No account required; settings are stored locally on your device.
Official download (EXE) System requirements

Code signing and integrity

  • Signature: Windows Authenticode (SHA‑256).
  • File name: CDXWin64v1.10.33.exe
  • Verify: Right‑click file → Properties → Digital Signatures → ensure the signature is valid.
  • Checksum: See the Download page for the latest SHA‑256 and release notes.
Tip: Always download from the canonical URL and avoid repackaged mirrors. This preserves the signature chain.

Privacy on this website

  • Analytics: We use Google Analytics 4 to measure visits and downloads — only after you give consent in the cookie banner.
  • Cookies: If you decline, analytics is not loaded and no analytics cookies are set.
  • Storage: Your consent choice is stored locally in your browser (localStorage).

Privacy in the application

  • Local operation: Display EX runs locally and stores its settings on your device.
  • No account required: You can use Display EX without creating an account.
  • Network access: The app may use system display APIs and your GPU driver — it does not need continuous internet to operate core features.

Contact

If you have security or privacy questions, contact the publisher via the official website. Please include your OS build, GPU model and steps to reproduce any security concern.
