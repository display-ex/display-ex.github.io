System Requirements & Compatibility

Display EX runs on any modern 64-bit Windows PC. No additional runtimes, drivers or SDKs are required. Check the tables below to confirm your configuration is supported.

Minimum & recommended requirements

Operating SystemWindows 10 v1903 (64-bit)Windows 11 23H2 or later
ProcessorAny 64-bit CPUAny modern CPU (2018+)
RAM2 GB4 GB or more
Disk space50 MB100 MB (for profile backups)

Display connectionAny (VGA not supported)DisplayPort 1.4 or HDMI 2.0+ for HDR & high refresh

GPU compatibility

Display EX uses standard Windows Display Configuration APIs (DXGI / CCD) and does not require vendor-specific drivers or SDKs. The following GPU families have been tested and confirmed.

🔴 AMD

  • RDNA 3 (RX 7000 series)
  • RDNA 2 (RX 6000 series)
  • RDNA 1 (RX 5000 series)
  • Vega / Polaris (older)
  • AMD Radeon integrated

🟢 NVIDIA

  • RTX 40-series (Ada)
  • RTX 30-series (Ampere)
  • RTX 20-series (Turing)
  • GTX 10-series (Pascal)
  • GTX 900 series

🔵 Intel

  • Arc A-series / B-series
  • Iris Xe (11th gen+)
  • UHD 620/630/770
  • Intel HD (6th gen+)

Display connections

All digital display connections supported by Windows are compatible. Analogue VGA is not supported.

✓ DisplayPort 1.2 / 1.4 / 2.0
✓ HDMI 1.4 / 2.0 / 2.1
✓ USB-C / DisplayPort Alt Mode
✓ Thunderbolt 3 / 4
✓ DVI-D (digital)
✓ Docking station pass-through
✗ VGA (analogue — not supported)
