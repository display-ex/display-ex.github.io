Display EX — Changelog & Release Notes

Full version history for Display EX. Every release is listed with a summary of new features, improvements and bug fixes.

v1.10.33 June 8, 2026

Stability release focused on Windows 11 24H2 compatibility and HDR profile reliability. Recommended update for all users.

New
  • newPer-app profile triggers now support UWP (Microsoft Store) apps in addition to Win32 executables
  • newQuick-switch hotkey customisation — assign any global shortcut to switch between your two most recent profiles
  • newHDR peak brightness slider now available in profile settings for OLED displays
Improvements
  • improveProfile switching latency reduced by ~30% on systems with three or more monitors
  • improveTray icon now shows the active profile name on hover
  • improveInstaller package size reduced by 18%
Bug fixes
  • fixFixed HDR not restoring correctly after system sleep/wake on Windows 11 24H2
  • fixFixed DPI override occasionally not applying on secondary monitor after reboot
  • fixFixed crash on launch when a previously-connected monitor is no longer available
  • fixFixed profile import dialog not accepting paths with non-ASCII characters
v1.10.29 April 14, 2026

Refresh rate management overhaul and improved support for variable refresh rate (VRR / G-Sync / FreeSync) monitors.

New
  • newVariable refresh rate (VRR) toggle per profile — enable/disable G-Sync or FreeSync as part of a saved preset
  • newRefresh rate profiles now support fractional values (e.g. 23.976 Hz, 59.94 Hz) for video work
Improvements
  • improveRefresh rate detection now correctly enumerates all supported modes on AMD RDNA 3+ GPUs
  • improveProfile editor UI refreshed with clearer grouping of display vs. colour vs. scaling settings
Bug fixes
  • fixFixed 240 Hz mode not appearing in profile dropdown on certain NVIDIA RTX 40-series configurations
  • fixFixed profile auto-trigger not firing for apps launched via Steam
v1.10.21 February 3, 2026

DPI and ClearType improvements, plus a new guided setup wizard for first-time users.

New
  • newFirst-run setup wizard detects connected monitors and suggests an initial profile configuration
  • newPer-app DPI override list with import/export support
Improvements
  • improveClearType calibration tool now accessible directly from the main window
  • improveImproved blurry-app detection — auto-suggests DPI overrides for known-affected applications
Compatibility
  • compatVerified compatibility with Windows 11 23H2
  • compatIntel Arc A-series GPU display enumeration fixed
v1.9.x series 2025

v1.9 series introduced the initial per-app profile trigger system, HDR support and multi-monitor preset import/export. Versions 1.9.0 through 1.9.45 were released over the course of 2025. Upgrade to v1.10.33 for the latest improvements.
